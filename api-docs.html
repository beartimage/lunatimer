lunatimer API

lunatimer is a client-side timer app. Its machine-readable surface is intentionally small: a health/status endpoint and Markdown for Agents content negotiation on the public pages.

Machine spec (OpenAPI 3.1): /openapi.json · Catalog (RFC 9727): /.well-known/api-catalog

Health / status

GET /api/health → application/json

{ "status": "ok", "service": "lunatimer" }

Markdown for Agents

Every public page returns HTML by default. Send Accept: text/markdown to receive a clean, formatting-stripped markdown representation instead.

curl -H "Accept: text/markdown" https://lunatimer.app/
PathContent
/Overview + links to each timer
/timerMeditation timer
/pomodoroPomodoro focus/break cycles
/timeboxTime-blocked task list

HTML responses for these paths also carry a Link: <…>; rel="alternate"; type="text/markdown" header advertising the markdown alternative, and Vary: Accept for correct caching.
